AXE FIND — это утилита для Windows, предназначенная для поиска ключевых слов в логах электронного логбука (ELD logbook).

---

## 🔍 Что делает программа

Программа автоматически находит следующие в логе:

- `violation`
- `certified`
- `disconnected`
- `monitoring`

Это помогает быстро выявить возможные нарушения или важные события в логах водителей.

---

## ⚙️ Возможности

- ✅ Быстрый анализ ELD логов
- 🧠 Поиск по ключевым словам
- ⚡ Не требует установки

---

## 🧑‍🏭 Как использовать

1. Скачайте `AXE FIND.exe` из раздела [Releases](https://github.com/AXE-KINGmain/Download-ELD/releases/tag/Downlaod-ELD).
2. Запустите файл двойным щелчком.
3. Пройдите регистарцию

---

## 🖥️ Системные требования

- ОС: Windows 10 или выше
